# domova.ch

Website von Domova, der digitalen Verwaltung für Eigentümergemeinschaften (7venture GmbH, Bern).

Statische Seite ohne Build-Schritt: `index.html`, Rechtsseiten, `site.css`, Schrift in `fonts/`.
Ausgeliefert über GitHub Pages aus dem Zweig `main`, eigene Domain in `CNAME`.

Ändern: Datei bearbeiten, committen, pushen. Nach etwa einer Minute ist die Änderung live.
